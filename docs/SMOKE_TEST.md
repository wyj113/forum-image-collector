# 浏览器发布前检查

自动测试使用合成 DOM 和 Chrome API 替身。以下清单需要在真实 Chrome 中执行；未打勾不等于通过。只使用你有权访问和保存的内容。

记录环境：系统版本、Chrome 版本、扩展版本、测试日期、站点布局类型。公开报告使用中性布局描述，不粘贴私人地址或签名链接。

- [ ] 从 release ZIP 解压，加载 `extension/`；控制台无启动错误。
- [ ] 首次启动跟随浏览器语言；选择中文／English 后重新打开面板仍保留选择。
- [ ] 扫描、去重或下载运行中切换语言，进度、状态和错误随之变化，勾选、筛选与任务队列不重置。
- [ ] 当前页只列出正文图片，排除头像、引用、表情与签名。
- [ ] 拒绝站点访问后没有启动批操作；再次点击允许后可正常继续。
- [ ] 指向查看页、相册或其他图床的图片标为暂不支持，没有偷偷保存缩略图。
- [ ] 图片 CDN 权限单独申请；登录失效显示失败且可以检查来源后重试。
- [ ] 关键词、全部／可下载／失败／已完成／重复／不支持筛选符合列表状态。
- [ ] 筛选后 ⌘/Ctrl、Shift、全选、取消和下载只作用于可见图片；隐藏选择仍保留。
- [ ] 正确保存文件，下载完成后显示已保存；浏览器中断下载时显示失败。
- [ ] 重试只保存可见已选的下载失败项，不重复保存成功项；去重失败不会被当成下载重试。
- [ ] 两个不同地址、相同文件字节被去重；视觉相似但不同字节的文件仍保留。
- [ ] 兼容整帖从第 1 页按顺序收集；停止后续扫不遗漏或重复已提交页面。
- [ ] 切换 1–4 路并发仍可操作，下载并发不超过所选数量。
- [ ] 任务结束后临时后台标签被清理；关闭面板再打开时没有旧进度。

把执行结果和未验证项写入 [VALIDATION.md](VALIDATION.md)，再更新发布说明。README 截图仅使用合成数据，不替代上述验证。
